# Iris Flower Classification Using Machine Learning

## Overview
This project predicts Iris flower species from four measurements using two supervised machine learning algorithms: Decision Tree and K-Nearest Neighbors (KNN).

## Dataset
The Iris dataset is provided by scikit-learn and contains 150 samples, four numerical features, and three flower species.

Dataset documentation: https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_iris.html

## Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab / Jupyter Notebook

## Workflow
1. Load and inspect the dataset.
2. Check missing values and examine the features and target.
3. Split the dataset into training and testing sets.
4. Train Decision Tree and KNN classifiers.
5. Compare accuracy scores and confusion matrices.

## Results
- Decision Tree accuracy: 93.33%
- KNN accuracy: 93.33%
- Better-performing model: Both models achieved equal test set accuracy.

## How to Run
1. Open `iris_classification.ipynb` in Google Colab or Jupyter Notebook.
2. Run the notebook cells in order.
3. Review the accuracy scores and confusion matrices.

## Conclusion
This project demonstrates a basic machine learning workflow, from data preparation to model evaluation, and compares two classification algorithms on the same dataset.
